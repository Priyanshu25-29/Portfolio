# Priyanshu Kumar — Developer Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript. No build tools are required.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For best testing, use a local server (for example, VS Code Live Server).

## Deploy
You can deploy the folder to Netlify by dragging it into Netlify Drop, or connect a GitHub repository and set the publish directory to the project root. No build command is needed.
